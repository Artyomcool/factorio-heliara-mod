# weathered_siliceous_crust — pipeline

## Выходной файл

`heliara/graphics/terrain/heliara_weathered_siliceous_crust.png` — 1024×1024 sprite sheet (HD формат).

## Структура sprite sheet

```
x=0                         x=768  x=1024
y=0    ┌──────────────────────────────────┐
       │  4×4 ряд 1  (спрайты 0-3, 256px)│
y=256  ├──────────────────────────────────┤
       │  4×4 ряд 2  (спрайты 4-7)       │
y=512  ├──────────────────┬───────────────┤
       │  4×4 ряд 3       │  1×1 (16шт)  │
       │  (спрайты 8-10)  │  4×4 = 64px  │
y=768  ├──────────────────┴───────────────┤
       │  2×2 (16шт, 8 cols × 2 rows)    │
y=1024 └──────────────────────────────────┘
```

Lua-конфигурация (`tile_hd`):
- `count=11, size=4, line_length=4, x=0, y=0`
- `count=16, size=1, line_length=4, x=768, y=512`
- `count=16, size=2, line_length=8, x=0, y=768`

## Инструмент 1 — Тайл-редактор

```bash
python3 art_sources/tiles/tile_editor_gui.py
```

Редактирует sprite sheet тайла. Фоновое изображение берётся из `textures/base_bg_a2.png` (1024×1024); при экспорте результат сохраняется в `heliara/graphics/terrain/`.

### Интерфейс

- **Левая панель** — SheetView: вся текстура тайла с цветными границами спрайтов (красный=1×1, синий=2×2, жёлтый=4×4). Клик → выбрать спрайт.
- **Правая панель** — SpriteEditor: превью выбранного спрайта, список оверлеев, поле **Вес** (1–10000, дефолт 100).
- **Кнопка ↺ Откатить тайл** — восстанавливает PNG из бэкапа в `art_sources/tiles/originals/` и сбрасывает все оверлеи.
- **Кнопка ⚡ Экспортировать** — сохраняет результат (фон + оверлеи) в игру и записывает `tile_state.json`.

### Оверлей (диалог редактирования)

Каждый оверлей накладывает маску из библиотеки на спрайт, используя кроп из исходной текстуры:

| Параметр | Описание |
|----------|----------|
| **Поз X / Поз Y** (cx, cy) | Координата кропа в исходной текстуре — тащи виджет-текстуру или двигай слайдером |
| **Маска X / Маска Y** (mx, my) | Смещение маски внутри спрайта — тащи превью или двигай слайдером |
| **Угол** | Поворот маски (0–359°) |
| **Масштаб** | Масштаб маски (10–300%) |
| **Alpha** | Непрозрачность маски (0–1000%) |
| **Blend** | Смягчение контраста в ярких областях (0–100%) |
| **Flip H / V** | Зеркальное отражение |

**Синяя зона** в превью — части маски, выходящие за границы спрайта.

**Drag по превью** — двигает маску (mx, my). Drag по виджету-текстуре — сдвигает кроп (cx, cy).

### Файлы состояния

| Файл | Описание |
|------|----------|
| `art_sources/tiles/tile_state.json` | Оверлеи и веса всех спрайтов; загружается при старте |
| `art_sources/tiles/originals/{name}.png` | Бэкап тайла до первого экспорта |

### Вес спрайта

Поле **Вес** в правой панели задаёт relative weight варианта в `tile_hd()`. Используется при генерации Lua (планируется). Сохраняется в `tile_state.json` под ключом `_weights_`.

## Инструмент 2 — Декаль-пикер

```bash
python3 art_sources/weathered_siliceous_crust/scripts/decal_picker_gui.py
```

Подбирает декали для размещения поверх тайла. Фон превью — `tiles/base_128.png`.

**Управление:**
- Кнопки **W** и **H** (1–8) — размер декали в тайлах (64 px/тайл); сразу генерирует 16 вариантов
- **↺ Regenerate** — новый набор (другие кропы и повороты)
- Клик по декали → добавить в набор
- Двойной клик по декали в наборе → открыть диалог редактирования

**Диалог редактирования декали** имеет те же параметры что и тайл-редактор: cx/cy (кроп текстуры), mx/my (смещение маски), угол, масштаб, alpha, blend, flip. Drag по превью — двигает маску; drag по виджету-текстуре — сдвигает кроп. Синяя зона — выход маски за границу декали.

**⚡ Generate sprite sheet** → сохраняет:
- `heliara/graphics/terrain/heliara_weathered_siliceous_crust_decals.png`
- `art_sources/weathered_siliceous_crust/textures/decals_layout.json`
- Автоматически вызывает `generate_decal_lua.py` → `heliara/decal/weathered_siliceous_crust.lua`

### Привязка декалей к тайлу

Lua привязка (авто-генерируется) задаёт `tile_restriction = { "heliara_weathered_siliceous_crust" }`.
В `data-updates.lua` все `heliara_wsc_decal_*` находятся динамически (не хардкодятся).

## Инструмент 3 — LUT-редактор

```bash
python3 art_sources/lut/lut_editor_gui.py
```

Создаёт цветовые LUT-таблицы для эффекта день/ночь на Heliara.

- Формат: 256×16 PNG, x = b_slice×16 + r_idx, y = g_idx
- `daytime=0.0` = полдень, `daytime=0.5` = полночь
- Три пресета: **day** (identity 0.0–0.25 и 0.75–1.0), **dawn/dusk** (0.35, 0.65), **night** (0.45–0.55)
- Параметры пресета: насыщенность, яркость, оттенок, сила оттенка
- **Save** → сохраняет PNG в `heliara/graphics/lut/` и патчит `day_night_cycle_color_lookup` в `heliara/planet.lua`

## Параметры нормализации масок (общие)

- значения ниже 20% → прозрачно
- значения выше 80% → непрозрачно
- линейный градиент между ними
- border fade (1px): `arr[0,:]=arr[-1,:]=arr[:,0]=arr[:,-1]=0`
